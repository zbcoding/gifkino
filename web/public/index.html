Gifkino

Edit animated GIFs. Import videos as resized GIF animations, add text, arrows and shapes, then export optimized GIFs with an updating size.

Download for Linux Open in browser Source on GitHub

Features

  • Open videos, GIFs and images, with automatic resizing on import for large files.
  • Overlays scoped to frame ranges: text, shapes (rect, ellipse, arrow) and images, placed on the frames you pick.
  • Frame list editing: reorder, duplicate, delete, retime, cut/copy/paste, drop one frame in every N, and smart-drop the frames that move the least.
  • Frame effects: mirror, fade in or out, and cross-fade the end into the start for a seamless loop.
  • Translated UI.
  • Optimized GIF export.

Install

Both builds are self-contained and carry the ffmpeg, ffprobe and gifsicle programs the editor uses.

  • Flatpak brings its own GTK and runs anywhere Flatpak does: flatpak install --bundle Gifkino.flatpak
  • AppImage needs glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40). chmod +x it and run it.
